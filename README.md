# ML Learning Journey

A collection of small, practical projects created while learning machine learning and data analysis.

## Projects

- `projects/canada-gasoline-eda/` — exploratory analysis of Canadian gasoline prices.
- `projects/airline-feature-engineering/` — feature engineering and exploratory analysis of airline ticket prices.

Each project can include its own notebook, source data instructions, and project-specific documentation. Python virtual environments and downloaded CSV files are excluded from Git; recreate the environment and download source data using each project's instructions.
